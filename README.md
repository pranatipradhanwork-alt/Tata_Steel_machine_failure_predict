# Machine Failure Prediction

A machine learning project exploring predictive maintenance for manufacturing equipment. The goal is to use machine operating data to identify potential failures early and help maintenance teams prioritize inspections.

> **Project status:** Setup in progress. Dataset analysis, model results, and application details will be added as the project develops. The provided dataset is described as synthetic, so results should be treated as a learning prototype rather than evidence of production readiness.

## Planned workflow

- Understand and clean the dataset
- Explore feature distributions and failure rates
- Prepare features and target without data leakage
- Compare classification models
- Evaluate precision, recall, F1-score, and confusion matrix with class imbalance in mind
- Explain influential features
- Optionally build a Streamlit demonstration

## Tech stack

Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn. Additional libraries will be added only if used.
